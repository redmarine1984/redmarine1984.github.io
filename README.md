## Featured Projects

### Dungeon Master Dice Roller

A Visual Basic desktop application designed for Dungeon Masters playing Dungeons & Dragons. The program simulates dice rolls from `1d4` to `1d20` and includes support for advantage and disadvantage rolls.

Repository:  
[Dungeon Master Dice Roller](https://github.com/Tim-McIntyre_tile/DiceRoller)

### Cell Phone Repair Inventory Tracker

A Visual Basic and SQL-based inventory tracking application developed for a cell phone repair business. The program allows users to add and remove products, assign pricing, track stock levels, and identify low-stock items. The application automatically creates the SQL database on first launch.
