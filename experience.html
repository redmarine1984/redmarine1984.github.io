Personal Project

Dungeon Master Dice Roller

A Visual Basic application that simulates dice rolls for a Dungeon Master running Dungeons & Dragons games. The program supports standard tabletop dice from 1d4 through 1d20, making it easier to quickly roll during encounters and gameplay.

The application also includes advantage and disadvantage roll options, helping Dungeon Masters handle common D&D mechanics without slowing down the session.

Business Utility Project

Cell Phone Repair Inventory Tracker

A Windows inventory tracking program developed for a friend’s cell phone repair business. The application allows users to add and remove products, assign pricing to each item, and monitor inventory levels.

The program stores its data in an SQL database and is designed to automatically create the database the first time the application runs, reducing setup work for the user.
